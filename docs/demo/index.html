요청 하나가 서버를 지나가는 길

그림 속 블록 위에 놓인 요청을 하나 고르고 클라이언트를 눌러 보세요. 헬스체크 /healthz 와 정적 파일은 프런트가 직접 답하고, /api/echo 만 프록시가 백엔드로 넘겨요. 파서가 거절한 요청은 라우팅까지 가지 않아요. 백엔드를 누르면 꺼지고, 프록시를 누르면 failover 가 바뀌어요.

이 페이지는 서버를 실제로 돌리지 않아요. 지나가는 길은 handler_route · proxy_pick_backend · proxy_mark_down · up_start_attempt 의 규칙을 옮긴 거고, 상태 코드 · Content-Type · 바이트 수는 실제 서버로 잰 값을 넣었어요 (맨 아래 표). 단, docs/demo/run-local.sh 로 띄워서 보면 실서버 모드를 켤 수 있고, 그때는 요청을 우리 서버에 진짜로 보내서 예상과 비교해요.
